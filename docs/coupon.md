# 노즈 시험편 사용 안내

테스터 본체를 인쇄하기 전에, 작은 시험편으로 두 가지 치수를 실물에 맞춰 정합니다. 여기서 정한 값은 본체 모델(`cad/params.py`의 `PROBE_SPACING`, `GROOVE_W`)에 반영됩니다.

- **프로브 간격**: 두 철사 끝의 중심 간 거리입니다. 검사 기판에서 1N4148WS(SOD-323)의 두 패드 중심 간 거리와 같아야 합니다.
- **홈 폭**: 잘라낸 LED·저항 다리가 끝까지 눌려 들어가고, 흔들어도 빠지지 않는 폭입니다.

같은 단계에서 **파란 LED 손 테스트**도 합니다. 파란 LED(Vf 약 2.8–3.3V)와 다이오드(약 0.6–0.7V)를 직렬로 연결하면 합계가 새 CR2025 전압(약 3.2V)과 비슷하거나 더 높습니다. 그래서 LED가 희미하거나 켜지지 않을 수 있으므로 실물로 확인합니다.

## 파일과 인쇄

`stl/nose-coupon.stl` 하나에 조각 4개가 들어 있습니다.

| 조각 | 각인 | 용도 |
|---|---|---|
| 노즈 3개 | `2.2` · `2.4` · `2.6` | 두 홈의 중심 간 거리(mm)가 각각 다릅니다. 홈 폭은 모두 0.6mm입니다. |
| 홈 폭 띠 | `0.4` · `0.5` · `0.6` · `0.7` | 홈 폭(mm)이 다른 홈 4줄입니다. |

- 프린터: Bambu, PLA, 0.4mm 노즐
- 레이어: 0.12–0.16mm를 권장합니다. 홈 깊이가 0.7mm, 각인 깊이가 0.4mm라서 0.2mm 레이어로 뽑으면 둘 다 뭉개질 수 있습니다.
- 방향: 파일 그대로(홈과 각인이 위쪽) 바닥에 눕혀 뽑습니다. 서포트는 필요 없습니다.
- 인쇄 시간은 몇 분 정도입니다.

코드로 다시 만들려면 다음 명령을 실행합니다. 두 명령 모두 결과는 출력 줄(`BUILD OK`, `CHECK OK`)로 판단합니다. `freecadcmd`는 실패해도 종료 코드 0을 돌려주기 때문입니다.

```sh
FC=/Applications/FreeCAD.app/Contents/Resources/bin/freecadcmd
$FC cad/coupon.py         # → BUILD OK stl/nose-coupon.stl
$FC cad/check_coupon.py   # → CHECK OK (간격·홈 폭을 STL 단면에서 직접 잰 값)
```

## 준비물

- 인쇄한 시험편
- 잘라낸 LED·저항 다리 여러 가닥. 끝은 니퍼로 **사선으로 잘라 뾰족하게** 합니다. 플럭스 잔여물을 뚫고 패드에 닿게 하기 위해서입니다.
- 파란 5mm LED 1개, CR2025 1개. 각인이 있는 넓은 면이 (+), 반대쪽 작은 면이 (−)입니다.
- 검사 기판. **전원은 반드시 끕니다.**
- 투명 테이프나 빨래집게, 확대경. 멀티미터는 있으면 좋지만 필수는 아닙니다.

## 확인 순서

세 단계를 차례로 진행합니다. 1단계에서 다리가 홈에 제대로 물리는지 먼저 확인하고, 2단계에서 그 다리를 노즈에 끼워 간격을 고른 뒤, 3단계에서 고른 노즈로 실제 판정을 해 보면서 파란 LED 밝기를 봅니다.

### 1단계 — 홈 폭 고르기

1. 홈 폭 띠의 각 홈에 다리를 한 가닥씩 눌러 넣습니다. 핀셋 뒷면이나 손톱을 쓰면 됩니다.
2. 기준:
   - 다리가 윗면 아래로 **끝까지 묻혀야** 합니다.
   - 띠를 뒤집어 흔들어도 **빠지지 않아야** 합니다.
   - 너무 좁으면 끝까지 들어가지 않거나 플라스틱이 갈라집니다.
   - 너무 넓으면 흔들 때 빠집니다.
3. 두 조건을 모두 만족하는 폭 중 **가장 좁은 것**을 고릅니다. 이것이 **선택한 홈 폭**입니다.

LED 다리는 단면이 네모(약 0.5 × 0.5mm)인 경우가 많고, 저항 다리는 원형입니다. 실제로 쓸 다리로 확인하세요.

### 2단계 — 프로브 간격 고르기

1. 노즈 3개에 다리를 두 가닥씩 끼웁니다. 노즈 끝 밖으로 약 **1.5mm**가 나오게 하고, 뒤쪽(손잡이 쪽)은 길게 남겨 둡니다.
   - 노즈 홈 폭은 0.6mm로 고정되어 있습니다. 1단계에서 고른 폭이 0.6이 아니면 다리가 헐겁거나 빡빡할 수 있습니다. 이때는 테이프로 임시 고정하고 **간격만** 판단합니다.
2. 기판 전원을 끄고, 확대경으로 보면서 노즈 끝을 1N4148WS에 댑니다. 두 다리 끝이 몸체 양쪽 바깥으로 드러난 **패드(납땜부) 위에 동시에** 올라가야 합니다.
3. 기준:
   - 두 끝이 모두 패드 위에 있어야 합니다.
   - 몸체(검은 부분)를 누르면 안 됩니다. 몸체는 절연체라 닿아도 반응이 없습니다.
   - 옆 부품을 건드리면 안 됩니다.
4. (선택) 멀티미터를 다이오드 모드로 두고 두 다리의 뒤쪽 끝 사이를 잽니다. 한 방향으로 약 0.5–0.7V가 나오면 두 끝이 모두 접촉한 것입니다.
5. 가장 안정적으로 닿는 노즈의 각인 값이 **선택한 프로브 간격**입니다.

### 3단계 — 파란 LED 손 테스트

2단계에서 고른 노즈를 그대로 써서, 실제 테스터와 같은 회로를 손으로 만듭니다.

1. 노즈 뒤쪽으로 나온 **다리 A**(노즈에 새긴 숫자를 바로 읽었을 때 왼쪽)를 파란 LED의 **짧은 다리(캐소드)**에 꼬아 잇습니다.
2. LED의 **긴 다리(애노드)**는 배터리 **(+) 면**에, **다리 B**의 뒤쪽 끝은 배터리 **(−) 면**에 대고 빨래집게나 테이프로 고정합니다. 두 다리가 배터리 옆 테두리에 닿지 않게 하세요. 테두리는 (+)이므로 다리 B가 닿으면 단락됩니다.
3. 자가 진단: 노즈 끝의 두 다리를 서로 맞대면 LED가 켜져야 합니다. 켜지지 않으면 배선부터 다시 확인합니다.
4. 노즈 끝을 기판의 1N4148WS 패드에 댑니다. 한 방향에서 켜지고, 180° 돌려 대면 꺼지는지 봅니다.
5. 실내 조명에서 켜진 밝기를 판단합니다.
   - **밝기 충분**: 파란 LED를 그대로 씁니다.
   - **희미함** 또는 **안 켜짐**: 빨간 5mm LED로 바꿔 같은 순서를 반복합니다. LED 구멍은 표준 5mm라서 본체를 다시 설계할 필요가 없습니다.

양방향 모두 켜지면 **판정 불가**입니다. 단락, 솔더 브리지, 또는 병렬로 연결된 부품 때문입니다. 이 경우는 간격 문제가 아니므로 다른 다이오드로 확인하세요.

```
1단계 홈 폭 → 2단계 간격 (노즈 3종 비교) → 3단계 고른 노즈로 판정 + 파란 LED 밝기
                                                   ↓ 희미 / 안 켜짐
                                             빨간 LED로 바꿔 3단계 반복
```
