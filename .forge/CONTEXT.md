# CR2025 LED 극성 테스터

CR2025 코인셀 하나와 표시 LED로, 검사 기판에 납땜된 다이오드의 방향을 확인하는 3D 프린팅 도구.

## Language

### 회로와 판정

**표시 LED**:
테스터에 직렬로 들어가 켜짐/꺼짐으로 판정 결과를 보여주는 LED.
_Avoid_: 테스트 LED, 인디케이터

**측정 대상 다이오드**:
극성을 확인하려는 다이오드. 이 프로젝트에서는 검사 기판에 실장된 1N4148WS(SOD-323).
_Avoid_: 테스트 다이오드, DUT(문서에서는 풀어 씀)

**프로브 A**:
표시 LED를 거쳐 배터리 (+)에 이어지는 끝. 측정 대상 다이오드의 애노드가 여기에 닿으면 표시 LED가 켜진다.
_Avoid_: + 프로브, 빨간 프로브

**프로브 B**:
배터리 (−)에 직접 이어지는 끝. 측정 대상 다이오드의 캐소드(띠 쪽)가 닿는 자리.
_Avoid_: − 프로브, 검은 프로브

**인서킷 측정**:
측정 대상 다이오드를 기판에서 떼지 않고 납땜된 채로 판정하는 것.
_Avoid_: 온보드 테스트

**판정 불가**:
양방향 모두 표시 LED가 켜지는 상태. 단락, 솔더 브리지, 또는 병렬로 연결된 부품 경로 때문이며 방향을 알 수 없다.
_Avoid_: 불량(원인이 여러 가지라 단정 불가)

### 기구

**노즈**:
프로브 두 끝을 받쳐 휘지 않게 하는 케이스 아래쪽의 가늘고 뾰족한 돌출부.
_Avoid_: 팁 홀더, 부리

**케이블 커버**:
노즈 구간의 열린 철사 홈을 덮어, 끝으로 패드를 누를 때 철사가 빠지지 않게 누르는 별도 인쇄 부품. 핀 2개로 노즈에 꽂는다.
_Avoid_: 클립, 뚜껑, 노즈 터널(철사를 꿰는 이전 방식)

**프로브 간격**:
프로브 A와 B 끝의 중심 간 거리. 검사 기판에서 측정 대상 다이오드의 두 패드 중심 간 거리와 같아야 한다.
_Avoid_: 피치(부품 리드 간격과 혼동)
